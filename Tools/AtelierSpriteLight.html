Atelier SpriteLight

Choisis les tiles d'un sprite (explosion, carapace, tir), règle sa lumière 3D et regarde-la éclairer la piste. Copie ensuite le bloc dans snes_hires.txt.

Bloc à copier

Dossier du pack HD

Le navigateur ne peut pas ouvrir un chemin tapé : le bouton ouvre le dossier (le chemin sert de mémo). Rien n'est envoyé : tout est lu dans ton navigateur. Les <include> sont suivis.

Aucun pack chargé : sprite d'exemple affiché.

Tiles du sprite

Charge un pack pour voir ses images de sprites.
Clique une image pour afficher ses tiles, puis clique les tiles à ajouter.

Les flips (<tile_hflip>…) ont le même hash : une seule ligne suffit.

Lumière

Mode

Scène d'aperçu

L'ambiance ne fait pas partie du bloc : elle assombrit l'aperçu pour mieux voir la lumière (comme un <m7ambient>). En jeu, la lumière n'existe que si le sprite est posé sur la piste.

Format du bloc

Références : à utiliser quand les tiles sont déjà définies ailleurs (ton .mesen). Lignes complètes : le bloc remplace leur définition (retire-les alors de l'autre fichier).
