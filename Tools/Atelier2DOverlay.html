Naissance

    
Mouvement

      
Angles : 0 = droite, 90 = bas, 180 = gauche, 270 = haut.

    
Apparence

    
Chaleur : deux ondes

      
Amplitude en px SNES, longueur d'onde en lignes SNES, vitesse en cycles/s, phase en degrés. Les deux ondes s'ajoutent.

    
Zone d'effet

      
Fractions de l'écran : X de 0 (gauche) à 1 (droite), Y de 0 (haut) à 1 (bas).

    
Rayons de lumière

      
L'origine (rayx, rayy) est une fraction de l'écran : 0,0 = coin haut-gauche. Angles : 0 = droite, 90 = bas. Pour un rayon oblique dans un coin, mettez l'origine à 0 / 0 et un angle entre 0 et 90 (ex. 45).

    
Aurore boréale

      
Rideaux qui dérivent. Le bas de la zone est le plus lumineux : placez « Y max » à l'endroit où la lumière doit s'arrêter. Tailles en px SNES (la passe NES utilise les px NES).

    
Couleur

      
Couleur du calque (hexa ou sélecteur). L'opacité est l'« Alpha global » de la carte Balise.

    
Ellipse

      
Coordonnées SNES. Avec « Négatif », tout l'écran est couvert sauf l'ellipse, qui montre la fenêtre de jeu.

    
Ombres, nuages, brouillard

      
Direction : 0 = droite, 90 = bas. Couverture : 0 = rien, 1 = tout l'écran.

    
Balise et ancrage

      
« Défilement simulé » imite la couche d'ancrage qui défile, pour voir l'effet de SpeedX / SpeedY. Il n'est pas exporté.
