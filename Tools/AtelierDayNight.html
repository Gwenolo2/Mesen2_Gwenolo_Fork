Atelier DayNight

Composez un cycle jour / nuit pour <DayNight> : étapes de couleur, maintiens, dégradés et brouillard. L'aperçu suit les règles de Mesen (mélange en lumière linéaire, torches non teintées, HUD épargné). Exportez le JSON dans le dossier effets\ du pack.

Cycle

Cliquez ou glissez sur la barre pour vous déplacer ; ←/→ : une image, Maj + ←/→ : une seconde ; Espace : lecture / pause. Traits pleins : début d'étape ; pointillés : début du dégradé ; triangle : image de départ (start) ; ⏸ : étape until (prévisualisée avec son maintien).
